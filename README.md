# 古法蓝晒底片整理室

运行：

```bash
npm start
```

访问`http://localhost:3040`。数据保存在`data/cyanotype-negative-room.json`。

## 复制订单结算台

访问`http://localhost:3040/orders`。订单绑定母版、成品尺寸、数量与加急标记，同一母版同时只保留一张未结束订单；基础价按尺寸×数量计算，加急与返工另计；预计药液超库存或缺纸时停在待备料且母版不占；生产登记成品、废片与实际用量，废片率超一成退回复核；尾款结清前成品留存、账面停在待出库。

- `src/orderCalc.js`：订单计算（尺寸价目、报价、用料估算、废片率与母版占用规则）
- `src/ledger.js`：成本账本（库存、备料检查、生产落账、收款与每单成本汇总）
- `src/orderPage.js`：操作页（结算台页面与交互）
