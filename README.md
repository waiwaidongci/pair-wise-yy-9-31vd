# 古法蓝晒底片整理室

运行：

```bash
npm start
```

- 底片整理：`http://localhost:3040/`
- 复制订单结算台：`http://localhost:3040/orders`

数据保存在`data/cyanotype-negative-room.json`。

## 复制订单结算台

订单绑定母版（底片）、成品尺寸、数量与加急标记；同一母版同时只保留一张未结束订单（待备料不占母版）。

- 基础价随尺寸和数量计算，加急费、返工费另计入账。
- 预计药液用量超过库存或缺少对应纸张时，订单停在`待备料`，补料后自动或手动重检。
- 生产填报成品、废片与实际用量，按实际用量扣库存、记成本；废片率超过一成退回复核，复核可退回返工（计返工费）。
- 尾款结清前成品留存，账面停在`待出库`；结清后订单`已结清`、母版释放。

业务文件：

- `src/orderPricing.js` — 订单计算：尺寸价目、用料估算、备料检查、状态规则
- `src/costLedger.js` — 成本账本：药液/纸张成本、加急与返工费、收款流水、单订单账面
- `src/orderDeskPage.js` — 操作页：开单试算、生产填报、复核、收款结清与账本视图
